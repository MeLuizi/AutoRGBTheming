Hardware, the program is designed for is MY hp victus 16 keyboard and my mouse (since I use openrgb to change the color the model doesnt matter, just make sure the index matches your mouse when you list the openrgb devices)

The bash script listens for changes in the theme files and whenever one happens it runs the python script to grab the primary hex and apply it to the rgb devices. With some color balancing witch doesnt work with all wallpaper colors but it works with most I use and its better than manually changing the rgb!
